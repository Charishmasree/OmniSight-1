# Week 4 – Image Cropping and ROI Detection

## Objective
To identify suspicious UI regions in webpage screenshots and crop them for focused visual analysis.

## Implementation
- Used the ImageCropper module from ai/optimizer.py.
- Implemented region-based image cropping.
- Identified suspicious UI areas such as overlapping text and clipped buttons.
- Used Region of Interest (ROI) to focus on important webpage sections.
- Generated separate cropped images for detected UI issues.

## ROI Detection
ROI stands for Region of Interest. It helps OmniSight focus on specific webpage areas that may contain visual defects.

## Benefits
- Focuses on important UI elements.
- Reduces unnecessary image processing.
- Helps analyze overlapping text and clipped elements.
- Supports efficient VLM screenshot analysis.

- clipped_elements_crop.png

## Result
Generated cropped image samples for suspicious UI regions to support focused visual defect analysis.
